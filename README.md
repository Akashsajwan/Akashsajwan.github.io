# Akash Sajwan — Data Analyst / BI Analyst Portfolio

A static, responsive portfolio website with a premium dark-tech visual system, scroll reveals, animated background glow, interactive navigation, project cards, experience timeline, certifications and resume download.

## Files
- `index.html` — page content
- `styles.css` — visual design + responsive layout
- `script.js` — navigation, scroll reveal, cursor glow, progress bar
- `resume.pdf` — resume download
- `favicon.svg` — favicon

## Run locally
Open `index.html` directly in a browser, or use any static server.

## Deploy
This is compatible with GitHub Pages, Netlify, Vercel static hosting, and similar services. Upload the contents of this folder as the site root.
